# MSAI-Business-Content-Public

Supporting files for the Colab notebooks used in the Master's in Artificial Intelligence in Business (MSAI in Business) program at Questrom School of Business, Boston University.

This repository holds a small set of files — mainly datasets — that course notebooks load directly (e.g., via raw GitHub URLs). It is not a general-purpose content repo.

## Contents

- `disney_plus_synthetic.feather` — a synthetic sample dataset used for in-class examples and exercises.

## Usage

Files here are referenced by path/filename from course Colab notebooks. If you add, rename, or move a file, update any notebooks that reference it.
